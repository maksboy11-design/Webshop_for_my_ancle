# Анимации

Один тип движения — один компонент в `src/ui/motion`. Страницы не заводят свои `@keyframes`.

| Тип | Компонент | Что меняется |
|---|---|---|
| fade | `Fade` | `opacity` |
| rise | `Rise` | `translateY` и тень при наведении |
| press | `Press` | `scale` в момент нажатия |
| reveal | `Reveal` | `opacity` и `translateY`, когда блок входит в экран |
| sheet | `Sheet` | `translateY` нижней панели фильтров |

Длительность — токен `--duration-ui` (240ms, ease-out). При `prefers-reduced-motion: reduce` токен становится 1ms, а декоративный сдвиг отключается.

Карточки (`src/ui/Card.tsx`) и кнопки используют только `Rise` и `Press`.

Исключение: пульс яркости прибора на первом экране остаётся в `Hero.module.css`. Это утверждённый сигнал конкретного слоя, не общий тип появления.
